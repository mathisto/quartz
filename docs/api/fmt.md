### `format1(): String` *(std/fmt.qz:10)*

String formatting functions

Usage:
  format1("Hello, {}!", "world")         # => "Hello, world!"
  format2("{} + {} = 3", "1", "2")       # => "1 + 2 = 3"
  format3("{}, {}, {}", "a", "b", "c")   # => "a, b, c"

All arguments must be strings. Use .to_s() to convert.
